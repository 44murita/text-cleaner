# Text Cleaner

Small Python script that cleans a text file and saves the result to a new file.

## Features

- Removes empty lines
- Removes spaces at the beginning and end of each line
- Converts text to lowercase
- Accepts input and output files from the command line

## Usage

```bash
python main.py input.txt output.txt
```

## Example

### Input:

```text
 Alice

BOB

 Charlie
```

## Output:
```
alice
bob
charlie
```
